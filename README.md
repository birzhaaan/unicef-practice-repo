# unicef-practice-repo

This repository is used for practicing the GitHub contribution workflow as
part of the DPG Track open source development course.

## Purpose

It simulates a full contribution cycle in a safe environment: reporting an
issue, creating a branch, opening a pull request that closes the issue, and
merging it.

## Workflow practiced here

- Creating and describing an issue
- Making changes on a separate branch instead of committing to `main`
- Linking a pull request to an issue with `Closes #N`
- Reviewing and merging a pull request
